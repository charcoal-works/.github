## 我们相信

- **本地优先。** 账号、会话和下载记录留在你的机器上，不经过我们的服务器。
- **不碰 DRM。** 只从商店取回你有权获取的包，不做解密、脱壳或修改。
- **开放。** 代码使用 Apache-2.0，问题、设计和路线图都公开。
- **可审计。** 不收集遥测；更新与下载都应有可验证的来源。
