## English

### Where to ask

| Topic | Where |
| --- | --- |
| Bug report | Open an issue with the bug report form |
| Feature idea | Open an issue with the feature request form |
| Usage questions | GitHub Discussions |
| Security issue | `security@charcoal-works.com` — never a public issue |
| Conduct concern | `conduct@charcoal-works.com` |

### Before opening an issue

1. Search existing issues and discussions.
2. Update to the latest release.
3. Reproduce with a clean profile if possible.
4. Collect the version, OS version, and relevant logs.

**Remove Apple ID / Google credentials, 2FA codes, session tokens, and any
personal data before posting logs.**

### What we cannot help with

- Recovering an Apple or Google account
- Bypassing DRM, FairPlay, or paid-app restrictions
- Injecting or installing packages on devices that are not yours
- Problems caused solely by a third-party store, network, or proxy

### Response expectations

This is a volunteer project. We aim to acknowledge security reports within three
business days; regular issues and discussions are handled on a best-effort basis.

## 简体中文

### 去哪里提问

| 类型 | 渠道 |
| --- | --- |
| Bug | 用 bug report 模板开 issue |
| 功能建议 | 用 feature request 模板开 issue |
| 使用问题 | GitHub Discussions |
| 安全问题 | `security@charcoal-works.com`，不要开公开 issue |
| 行为准则问题 | `conduct@charcoal-works.com` |

### 开 issue 之前

1. 先搜索现有 issue 和 discussion。
2. 更新到最新版本。
3. 尽量在干净的环境里复现。
4. 收集版本号、系统版本和相关日志。

**发布日志前请删除 Apple ID / Google 凭据、双重验证码、会话 token 和个人数据。**

### 我们无法处理

- 找回 Apple 或 Google 账号
- 绕过 DRM、FairPlay 或付费限制
- 在非你所有的设备上注入或安装应用
- 仅由第三方商店、网络或代理导致的问题

### 响应预期

这是一个志愿者项目。安全问题我们争取在 3 个工作日内确认；普通 issue 和 discussion 按尽力而为处理。
