# Charcoal Works — organization profile

This repository hosts the public organization profile and the default community
health files for [Charcoal Works](https://github.com/charcoal-works).

- `profile/README.md` — rendered on the organization page
- `SECURITY.md` — vulnerability disclosure policy
- `CONTRIBUTING.md` — contribution guide
- `CODE_OF_CONDUCT.md` — community standards
- `SUPPORT.md` — where to ask for help
- `ISSUE_TEMPLATE/` — default issue forms
- `PULL_REQUEST_TEMPLATE.md` — default pull request checklist

GitHub automatically uses these files for repositories in the organization that
do not define their own copy.
